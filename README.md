SKYLANE COURIER — game penerbangan kurir di Kepulauan Senja: lima misi dengan tujuan berbeda, tiga tingkat kesulitan (Mudah/Normal/Sulit), ring penanda, bahan bakar dan kerusakan yang memaksa keputusan, serta pendaratan yang dinilai dari kelembutan dan ketepatan. Chase-view pseudo-3D di canvas 2D dengan HUD instrumen menyala (altitude, speed, heading, horizon buatan, throttle, fuel, damage, progress ring), audio prosedural WebAudio, menu jeda, layar debrief dengan skor terbaik, dan autopilot deterministik untuk screenshot.

v3 — revisi visual: pesawat lebih besar di frame dengan baling-baling blur dan lampu nav bercahaya; dunia kini punya tempat yang dikenali — Mercusuar Tanjung Biru dengan sorot berputar, Desa Senja dengan jendela hangat menyala, palem di pantai, laut berkilau dan kabut horizon; hujan diagonal saat badai. Keempat screenshot kini semuanya in-flight: pendekatan akhir ke landasan 27, kejar ring saat senja, kurir malam, dan badai beruntun.

## Run it

```sh
node serve.ts
# buka http://localhost:8080 di desktop Chrome
```
