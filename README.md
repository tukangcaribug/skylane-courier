SKYLANE COURIER — game penerbangan kurir di Kepulauan Senja: lima misi dengan tujuan berbeda, tiga tingkat kesulitan (Mudah/Normal/Sulit), ring penanda, bahan bakar dan kerusakan yang memaksa keputusan, serta pendaratan yang dinilai dari kelembutan dan ketepatan. Chase-view pseudo-3D di canvas 2D dengan HUD lengkap (altitude, speed, heading, horizon buatan, throttle, fuel, damage, progress ring), audio prosedural WebAudio, menu jeda, layar debrief dengan skor terbaik, dan autopilot deterministik untuk screenshot.

## Run it

```sh
node serve.ts
# buka http://localhost:8080 di desktop Chrome
```
